# Запись в салон «Ангелина» через Telegram

Заявка с сайта уходит в Cloudflare Worker, а он пересылает её администратору в Telegram. Токен бота хранится только в Cloudflare, на сайте его нет.

```
Сайт (форма) → Cloudflare Worker → Telegram-бот → чат администратора
```

## Что в папке

- `site/index.html` — сайт. Форма отправляет заявку на адрес из константы `BOOKING_ENDPOINT` в конце файла.
- `worker/src/index.js` — обработчик: проверяет заявку и отправляет сообщение в Telegram.
- `worker/wrangler.toml` — настройки Worker: имя и адрес сайта, с которого принимаются заявки.

## Запуск

Понадобятся Node.js и бесплатный аккаунт Cloudflare.

### 1. Бот

1. В Telegram откройте @BotFather, отправьте `/newbot`, задайте имя. Сохраните токен вида `123456:ABC…`.
2. Напишите своему боту любое сообщение из аккаунта администратора. Для рабочего чата добавьте бота в группу и напишите в ней.
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": …}`. Это `chat_id`. У групп он отрицательный.

### 2. Обработчик

```bash
cd worker
npx wrangler login
npx wrangler secret put TELEGRAM_TOKEN      # вставьте токен
npx wrangler secret put TELEGRAM_CHAT_ID    # вставьте chat_id
npx wrangler deploy
```

После `deploy` появится адрес вида `https://angelina-booking.<ваш-поддомен>.workers.dev`.

### 3. Сайт

1. В `site/index.html` замените `BOOKING_ENDPOINT` на адрес из шага 2.
2. Сайт публикуется на GitHub Pages через GitHub Actions автоматически при каждом изменении папки `site` в ветке `main` (Settings → Pages → Source: **GitHub Actions**). Адрес сайта: https://aperevedencev-glitch.github.io/angelina/ — папка `site` становится корнем сайта, поэтому `robots.txt`, `sitemap.xml` и `favicon.ico` лежат в ней.
3. В `worker/wrangler.toml` уже стоит `ALLOWED_ORIGIN = "https://aperevedencev-glitch.github.io"` — это домен без пути, так и должно быть. Если переедете на свой домен, впишите его сюда и снова выполните `npx wrangler deploy`.

### 4. Проверка

Отправьте заявку с сайта. Администратору придёт сообщение с именем, телефоном, услугой и датой.

## Что делает обработчик

- Принимает заявки только с адреса из `ALLOWED_ORIGIN`.
- Проверяет имя, телефон (10–15 цифр, `8…` приводится к `+7…`), услугу из списка и согласие на обработку данных.
- Отсеивает спам-ботов скрытым полем `website`: люди его не видят и не заполняют.
- Экранирует текст, чтобы заявка не ломала разметку сообщения.
- Если Telegram не ответил, сайт показывает ошибку и телефон салона.

## Перед запуском

- Замените в `site/index.html` цены, адрес и телефон (он есть в контактах и в тексте ошибки формы) и уберите плашку сверху.
- Если меняете список услуг в форме, поправьте массив `SERVICES` в `worker/src/index.js`, иначе новая услуга придёт как «Не указана».
